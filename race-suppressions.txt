# GORACE resolves this path relative to the process working directory, and
# `go test ./...` runs every package's binary in that package's own directory.
# So both the justfile and CI pass an absolute path built from the repo root
# rather than naming the file directly.

# route.NetworkManager.started is a plain bool. Start() writes it in the

# straight away — so every Box.Start on a host with a default route trips it.
#
# Nothing in our config avoids this: NewNetworkManager builds the monitor
